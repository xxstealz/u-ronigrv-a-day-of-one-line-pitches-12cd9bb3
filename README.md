# A Day of One Line Pitches — "Just Describe It"

One sentence, 195 characters, pitching a friend who has never coded on letting an AI agent build their first app idea on make.fun:

> Just describe the app idea you've been carrying around for months in plain words, and an AI agent on make.fun will build it for you — no code, no setup, free to enter, and the best ones win cash.

`main.ts` writes exactly that sentence to `/output/entry.txt`, where the gate reads it. Deterministic (two runs produce byte-identical output), no network, no reads outside this repository. The sentence is validated to 1–240 characters (code-point count) and a single line.

Run it: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
